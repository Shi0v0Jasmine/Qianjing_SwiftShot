## 修复过的问题

- 初始预览停在淡入前黑帧：改为从已显示的首镜帧进入预览。
- 浏览器预览中的图片 decode 警告：播放器使用浏览器图片，正式渲染继续使用 Remotion Img 等待资源就绪。
- 原 favicon 自动请求返回 404：添加品牌 SVG 与明确引用，复查通过。
- 重排后参考结构顺序跟随编辑移动：分析页按固定参考顺序展示，编辑顺序独立。
- 全页截图工具曾造成缩小留黑边：重新使用固定桌面视口采集展示视频截图。

## 实际限制

- 实时 AI 分析、真实图生视频和原版上传链路未在此版本复验。
- 演示中的初稿由预制图片运镜和字幕合成；它证明产品流程和编辑体验，不证明模型理解质量。
- 本机状态按浏览器站点保存，切换端口或浏览器需要恢复 JSON 备份。
- 未做大规模并发、生产部署或完整辅助技术审查；本地导出一次处理一个任务。
- KANO 和用户定位仍是研究假设，没有虚构用户样本或统计结论。
