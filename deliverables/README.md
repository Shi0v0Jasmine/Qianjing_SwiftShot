# 迁镜 ShotSwift 演示交付

- ShotSwift-demo-zh.mp4：完整中文展示视频，100 秒，1920×1080，30 fps，无音轨。
- ShotSwift-cover.png：展示视频封面。
- ShotSwift-style-sample.mp4：前 15 秒风格样片。
- ShotSwift-demo-zh.srt：可编辑的章节说明字幕。主要字幕已直接呈现在视频画面内，不必额外挂载此文件。
- 咖啡案例短片：../apps/web/public/demo/coffee-ad.mp4，21 秒，1080×1350，30 fps，无音轨。
- 可编辑视频源码：../apps/demo-video/src/。
- 产品/UI 文档：../docs/product-brief.md、../docs/ui-audit-and-design.md。
- 运行与演示指南：../docs/demo-presenter-guide.md。

在项目根目录双击“启动演示.cmd”，打开 http://127.0.0.1:4173 即可操作 demo。

视频采用本项目实际界面截图和 Remotion 动画讲解。示例图片与结构分析是预制内容；字幕、时长、素材、镜头顺序的编辑、动态预览和本机 MP4 导出真实可用。没有配音或背景音乐。
